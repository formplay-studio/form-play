05 / PROCESS

Direction
before generation.

좋은 결과는 더 많은 생성보다, 무엇을 바꿀지 분명하게 정하는 판단에서 시작됩니다.

01 / SOURCE

Read the subject.

인물의 시선, 젖은 머리와 블랙 테일러링에서 긴장감과 물성을 관찰했습니다.

BOLDTACTILEBURGUNDYDIRECT LIGHT
02 / DIRECTION

Set the rules.

인물의 존재감은 유지하고, 버건디 배경과 직접적인 빛으로 에디토리얼 언어를 강화했습니다.

03 / RESULT

Choose with intent.

색이 피부톤을 압도하지 않고, 의상의 질감과 그림자가 인물의 태도를 강화하는 결과를 선택했습니다.

  1. 01

    Observe

    원본 인물의 표정, 실루엣과 시선이 주는 인상을 관찰합니다.

  2. 02

    Direct

    빛, 팔레트, 공간과 감정의 기준을 언어로 설계합니다.

  3. 03

    Generate

    ChatGPT와 이미지 생성 도구로 여러 시각적 가능성을 탐색합니다.

  4. 04

    Curate

    목적에 맞는 결과를 선택하고 얼굴과 스타일의 일관성을 확인합니다.

  5. 05

    Refine

    HTML, CSS와 JavaScript로 비교 경험과 반응형 화면을 다듬습니다.
